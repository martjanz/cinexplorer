# Cinexplorer v1.1.0

Curaduría: ahora podés armar tus propias listas de películas, importar las
carpetas de `Collections/` como listas y unir a mano las películas guardadas en
varios archivos. Además, mejoras en el agrupado de partes y en la búsqueda en
TMDB.

Sigue siendo de solo lectura: las listas viven en el catálogo y nunca mueven,
renombran ni borran archivos de video.

## Descargas

| Sistema | Archivo |
|---|---|
| Windows (amd64) | `cinexplorer-windows.exe` |
| macOS (universal: Intel + Apple Silicon) | `cinexplorer-macos` |
| Linux (amd64) | `cinexplorer-linux` |

Para actualizar, reemplazá el ejecutable por el nuevo: el catálogo
(`cinexplorer.db`) y tus correcciones manuales se conservan. Recordá que el
binario de macOS no está firmado (clic derecho → Abrir, o
`xattr -d com.apple.quarantine cinexplorer-macos`).

## Novedades

### Listas

- **Página Listas:** crear, renombrar y borrar listas propias. Borrar una lista
  nunca toca archivos.
- **Agregar desde la ficha:** en cada película y versión, el botón **+** abre un
  menú para sumarla o quitarla de una lista; las listas a las que pertenece se
  ven como chips.
- **Explorar por lista:** nueva faceta **Lista**. Una lista se abre como
  Explorar filtrado por ella y se puede ordenar por *fecha de agregado a la
  lista* o por cualquiera de los órdenes de siempre.
- **También lo no identificado:** se pueden guardar archivos sin identificar;
  cuando se identifican, la lista los muestra como su película. Los extras y los
  archivos ignorados no se pueden agregar.
- **Inicio:** nuevas filas con las listas modificadas más recientemente.

### Importar `Collections/`

- **Revisar → Colecciones:** cada subcarpeta de una carpeta `Collections/` se
  ofrece como lista para **importar** (a una lista nueva o a una existente) o
  **descartar**.
- Lo que se agregue a la carpeta después se vuelve a ofrecer.

### Películas en varias partes

- **Agrupado más inteligente:** se unen las películas cuyos nombres difieren
  después de la marca de parte (`Part 1`, `CD2`…), sin fusionar secuelas cuyas
  partes tienen años distintos.
- **Unir a mano:** en el menú ⋯ de una versión, *Es una parte de…* la une con
  otra, y se puede deshacer. Las uniones sobreviven a nuevos escaneos y se
  rechazan las que formarían un ciclo.

### API

- Nuevos endpoints de listas (`/api/lists`) e importación de colecciones
  (`/api/collections/…`), y parámetro `lista` en `/api/explore`.
- Las fichas de películas y versiones incluyen el campo `lists`.
- Acciones de unir y separar partes. Detalle en el README.

## Correcciones

- Las búsquedas en TMDB ignoran las tildes de los títulos, lo que mejora las
  coincidencias.
- La detección de calidad reconoce nombres con tildes descompuestas (típicas de
  discos que pasaron por macOS).
- El selector de versiones usa el id de la versión, y los enlaces de partes no
  se duplican ni se pierden al escanear raíces enlazadas.
- Al desaparecer una versión del disco, sus entradas se quitan de las listas.
- La interfaz enfoca los campos que se despliegan, y los chips de lista
  vuelven a su estado anterior si el servidor devuelve un error.

## Limitaciones conocidas

Siguen vigentes las de v1.0.0: binarios sin firmar, `ffprobe` detectado solo al
arrancar, raíces en el mismo disco que la app y pérdida de las correcciones
manuales y las listas al borrar `cinexplorer.db`.
